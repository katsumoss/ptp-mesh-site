# ゲートウェイ一覧

近くに ptp mesh のゲートウェイ（GW）があれば、MQTT 設定なしで「[電波だけ参加](connect.md#gw-mqtt)」できます。

ここに載っているのは**運営が常設しているGW**です。どのグループに属するかは[グループ一覧](topics.md)を見てください。

!!! tip "いま動いているかは meshmap で"
    このページは設置場所とグループの一覧です。「今この瞬間の稼働状況」は **[meshmap.net](https://meshmap.net)** で確認してください（載る方法は[公式マップに載せる](map.md)）。

## 自分のGWを載せたい

GWを常設していて掲載してよければ、[リンク](links.md)のDiscordで声をかけてください。**掲載は任意**で、載せなくてもブリッジは同じように使えます。

載せるときにもらう情報:

- 公開してよい**目印の場所**（駅名・エリア名。**自宅の住所は載せません**）
- 使っている**ルートトピック**（`ptp/commons` など）
- **preset / slot**（当ネットワークは全GWが LongFast / slot12）
- 稼働時間（常時 / 夜間停止 など）
