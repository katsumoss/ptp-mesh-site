# グループ一覧

ptp mesh では **ルートトピック（root topic）がそのままグループ**です。同じルートトピックを設定した人どうしが1つの島になり、**グループを跨いだ配送は行いません**。

参加するときは、[参加方法](connect.md)のルートトピック欄に下の文字列をそのまま入れてください。

## 公開されているグループ

| ルートトピック | エリア | 性格 |
|---|---|---|
| `ptp/commons` | 東京（方南町駅周辺 / 千駄ヶ谷駅周辺）＋ 茨城（水戸〜ひたちなか）ほか外部参加者 | **みんなのグループ**。誰でも読み書きできる公開の島。迷ったらここ |
| `ptp/akiba-pcn` | 秋葉原ラジオデパート近辺 | 秋葉原ラインの島。commons とは**完全に隔離**されています |

グループはこの2つだけが公開されています。**`ptp/<好きな名前>` にすれば自分のグループをその場で作れます**（サーバーへの登録は不要）。ただしその島は他の誰とも繋がらないので、人を呼ぶなら名前を周知してください。

拠点ごとの詳しい位置は[ゲートウェイ一覧](gateways.md)を見てください。**いま動いているか**は [meshmap.net](https://meshmap.net) が確実です。

!!! note "ルートトピックは「仕切り」であって「秘匿」ではありません"
    ルートトピックは知っていれば誰でも入れる**ソフトな仕切り**です。中身を隠したい場合は、グループとは別に**名前付きチャンネル＋独自PSK**を追加してください。配送はトピック、秘匿はPSK、と層を分けて考えると迷いません。

## どのサーバーにあるか

グループはすべて **ptp mesh の自前サーバー** にあります。公式ブローカーとは別物です。

| | ホスト | 中身 |
|---|---|---|
| **ptp mesh（ここ）** | `160.16.104.222:1883` | `ptp/commons` / `ptp/akiba-pcn` |
| 公式ブローカー | `mqtt.meshtastic.org` | 世界中の公開メッシュ。[公式マップ掲載](map.md)はこちら経由 |

[防災チャンネル `ptp-bousai`](bousai.md) は**グループではなくチャンネル**です。`ptp/commons` の中を流れています（元データは公式ブローカーの JPEQ チャンネルから取り込んでいます）。

## トピックの決まり方

MQTTクライアントで直接覗きたい人向けです。トピックは**ノード側の設定から機械的に決まります**。

```
<ルートトピック>/2/e/<チャンネル名>/<GWのノードID>

例) ptp/commons/2/e/LongFast/!e0f79774
    ptp/commons/2/e/ptp-bousai/!626f7573
    ptp/commons/2/e/PKI/!6b626f74        ← 暗号化されたDM
```

- `2/e` は Meshtastic のプロトコル版と「暗号化済み」を表す固定部分です
- **チャンネル名がそのまま入る**ので、プライマリを既定のままにしていれば `LongFast` になります
- 末尾は**中継したGWのID**で、発信元のノードIDではありません
- `PKI` は個別DM用の枠です。**中身は当事者以外には復号できません**

購読するときは `ptp/#` で全部、`ptp/commons/#` でグループだけ、と絞れます。接続情報は[参加方法](connect.md)と同じ（`friend` アカウント）です。

!!! warning "commons は公開グループです"
    誰でも読み書きでき、**ルートトピックの文字列は接続した人からは見えます**。見られたくない会話は自分のグループ＋独自PSKで。
