# 防災チャンネル `ptp-bousai`

地震・気象警報・台風などの防災情報が**そのまま流れてくる**チャンネルです。設定すれば、こちらから問い合わせなくても受信できます。**参加は任意（オプトイン）**で、既存のチャンネルには一切影響しません。

聞くだけなら **MQTT接続は不要**です。名前とPSKを入れて、GWの電波が届く場所にいれば受信できます。

## 設定するもの（2つだけ）

アプリで**チャンネルを1つ追加**して、次の2項目を入れます。

| 項目 | 値 |
|---|---|
| 名前（Name） | `ptp-bousai` |
| PSK（事前共有鍵） | `Bg==` |

!!! warning "PSKの入力でつまずきやすい点"
    アプリのPSKは**キーサイズ（keysize）の選択**があります。`Bg==` は **1バイト**の鍵です。256bit などを選んだままだと入りません。**1 byte を選んでから** `Bg==` を入力してください。

- **チャンネルの位置（インデックス）はどこでも構いません**。チャンネルは名前とPSKで識別されるので、あなたの端末で何番目に置いても届きます（上限8つ）
- **プライマリチャンネルは変更しないでください**。追加するのはセカンダリ側です
- **Uplink は OFF のままで結構です**（受信専用）

!!! tip "GWを運用している人へ"
    このチャンネルの **Downlink を ON** にしてください。**GWが復号できないチャンネルは電波に再放射できない**仕様なので、Downlink が入っていないと「設定したのに何も来ない」状態になります。
    また `--ch-set` は**1回に1項目ずつ**打ってください（まとめると通らない既知の罠があります）。

    ```bash
    meshtastic --host <ノード> --ch-index 2 --ch-set name ptp-bousai
    meshtastic --host <ノード> --ch-index 2 --ch-set psk base64:Bg==
    meshtastic --host <ノード> --ch-index 2 --ch-set downlink_enabled true
    ```

    ※CLIは1バイト鍵を `psk=simple5` と表示します（`Bg==` = 0x06 と同じものです）。

## 届き方

- **足切りはしていません**。震度1でも流れます。「重要なものだけ」ではなく**全部**です
- **1つのできごとが複数のメッセージに分かれて届きます**。手を加えず素通しで流しているためで、たとえば地震1件で**6通**（見出し → 詳細 → 地図URL → 最大震度 → 有感地域 → 津波の有無）が**約12秒間隔**で届きます。**故障ではありません**
- 平時の流量は**1時間あたり3〜4通**程度です（実測。内訳は気象警報が約半分、地震と台風が残り）
- 文面は**英語（ASCII）のまま**です。端末内蔵フォントの都合と、1パケット237バイトという制限のためです

**問い合わせ型がよければ** [kbot](kbot.md) を使ってください。こちらは1件を1通に要約して返すので、流量が気になる人にはそちらが向いています。両者は独立していて、**片方だけ使っても構いません**。

## 気象庁のローマ字地名の読み方

地名は気象庁の表記そのままなので、**日本語話者ほど読みにくい**ものがあります。実際に流れてきた地名から拾いました。

| 表記 | 読み |
|---|---|
| `Kaetsu NIIGATA` | 下越（新潟） |
| `Chuetsu NIIGATA` | 中越（新潟） |
| `Joetsu NIIGATA` | 上越（新潟） |
| `Sado NIIGATA` | 佐渡（新潟） |
| `Okitama YAMAGATA` | 置賜（山形） |
| `Aizu FUKUSHIMA` | 会津（福島） |
| `Kaga ISHIKAWA` | 加賀（石川） |
| `Noto ISHIKAWA` | 能登（石川） |
| `Satsuma, KAGOSHIMA` | 薩摩地方（鹿児島） |
| `Near Tokara Islands, KAGOSHIMA` | トカラ列島近海（鹿児島） |
| `Hyuganada Sea, KYUSHU Region` | 日向灘（九州地方） |
| `Off Tomakomai, HOKKAIDO` | 苫小牧沖（北海道） |

方角の付く地名は**そのまま県内の区分**です。

| 表記 | 読み |
|---|---|
| `Northern IBARAKI` / `Southern IBARAKI` | 茨城県北部／南部 |
| `Eastern MIYAGI` / `Western MIYAGI` | 宮城県東部／西部 |
| `Eastern TOYAMA` / `Western TOYAMA` | 富山県東部／西部 |
| `Southern NAGANO` | 長野県南部 |
| `Southern HIROSHIMA` | 広島県南部 |

## メッセージ中の記号

| 記号 | 意味 |
|---|---|
| `M2.7` | マグニチュード |
| `I:1` | 最大震度（Intensity） |
| `D:20km` | 震源の深さ |
| `[FINAL]` | 確定情報 |
| `PRELIMINARY` | 緊急地震速報＝**確定前**。あとから数字が変わります |
| `[EEW #N]` | 緊急地震速報の第N報 |
| `<D/G>` | 警報の解除・引き下げ |
| `L:3->2` | 警戒レベル相当が3から2へ下がった |
