# kbot（情報bot）

**kbot** は ptp mesh に常駐している問い合わせ用のbotです。話しかけると、地震・気象警報・台風などの防災情報を**その場でDMで返します**。

電波を出す実体のノードはありません。サーバー上の仮想ノード（`!6b626f74`）として動いていて、**各グループのプライマリチャンネル**に居ます。commons に居る人も、自分のグループを作った人も、**トピックを切り替えずに同じ情報**を引けます。

## 話しかけ方

| 方法 | 書き方 | 例 |
|---|---|---|
| **DM（推奨）** | ノード一覧から `kbot` を選んでDM。**先頭の `kbot` は不要** | `eq` |
| チャンネルで全体宛 | **先頭に `kbot` が必須** | `kbot eq` |

**返信は必ずDMで返ります**（全体宛に聞いた場合も）。チャンネルが答えで埋まらないようにするためです。

!!! warning "最初の1回は返ってこないことがあります"
    DMは相手の公開鍵を知ってから成立する仕様（Meshtastic共通）です。kbotがあなたの鍵をまだ持っていないときは、**その場でNodeInfoを要求してから**返します。**返事が無ければもう一度だけ送ってみてください**。2回目からは普通に返ります。

## コマンド一覧

| コマンド | 別名 | 返るもの |
|---|---|---|
| `eq` | `quake` / `earthquake` | 最新の地震。`eq 2` `eq 3` で複数件（最大3件） |
| `wr` | `warn` / `weather` | いま有効な気象警報（地域×種別） |
| `ty` | `typhoon` | 台風情報 |
| `status` | `st` | 情報の鮮度（最終受信・24hの件数）と出典 |
| `help` | `?` / `kbot` 単体 | 1行のコマンド一覧 |
| `get time` | `time` | 現在時刻（JST） |
| `ping` | — | `pong` を返す |

`ping` は**経路の切り分け**用です。防災情報のデータ経路を通らずに「自分 → RF → GW → サーバー → DM → GW → RF → 自分」の往復だけを試せます。

## 実際の返答（本番から取得）

```
help    cmds: eq=quake wr=weather-warning ty=typhoon status=freshness | get time | ping

eq      EQ 07/27 13:56 M2.7 I:1 | Near Tokara Islands, KAGOSHIMA
        | Max:Akusekijima,ToshimaMura, KAGOSHIMA | NO TSUNAMI [FINAL] (10h ago)

wr      no active WR (last update 1h ago)

ty      TY2613 DOLPHIN 998hPa W:20m/s(Gust 30m/s) at(13.7N,175.3E) mv W 30km/h (2m ago)

status  JPEQ, last msg 2m ago, SCH_TX 3h ago, 24h EQ5 WR15 TY3 EEW1. src:JPEQ by YNGMT
```

`I:1` は震度1、`M2.7` はマグニチュード、`D:20km` は震源の深さです。`[FINAL]` は確定情報、`PRELIMINARY` が付いていれば**緊急地震速報（確定前）**なので、あとから数字が変わります。

地名は気象庁のローマ字表記そのままです。読み解きは[防災チャンネルのページ](bousai.md#jma)にまとめてあります。

## 仕様（知っておくと迷わない点）

- **知らないコマンドには何も返しません**。雑談のたびにDMが飛ぶとうるさいので、**黙る**のが仕様です。反応が無い＝コマンドとして解釈されなかった、と考えてください
- **返答は必ず1行・英数字（ASCII）のみ・200バイト以内**。LoRaの1パケットに収めるためです。日本語にすると1文字3バイトで入る情報が1/3になるため、あえて英語のままにしています
- **同じ相手からの連投は5秒に1回**まで
- 情報が古いままかどうかは `status` で分かります。上流が止まっていても `eq` は**黙って古い値を返し続ける**ので、疑わしいときは `status` を見てください

## 出典

地震・気象警報・台風の情報は **JPEQ（YNGMTさん）** の配信内容を、許可を得て転載しています。kbot が返す内容の正確性・即時性は保証できません。**避難などの判断は必ず気象庁・自治体の公式情報で**行ってください。

同じ情報を**問い合わせずに受け取りたい**場合は、[防災チャンネル `ptp-bousai`](bousai.md) を設定してください（kbotとは独立した別系統です）。
